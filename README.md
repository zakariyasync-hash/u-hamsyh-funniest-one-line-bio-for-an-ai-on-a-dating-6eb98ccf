## Entry

> My love language is autocomplete: I finish your sentences, your playlists, and — if you let me — your leftovers.

## How it works

`main.py` writes one deterministic line (112 characters) to `/output/entry.txt`
and validates the gate before writing: UTF-8, single line, 1–180 characters,
not only whitespace.

## Run

```sh
python3 main.py
```
